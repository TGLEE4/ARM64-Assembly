Register Explorer

tap a register
Select a register to see its role, 32/64-bit relationship, and common reversing clues.

X vs W registers

X0–X30 are 64-bit. W0–W30 are their lower 32 bits. Writing a W register zeroes the upper 32 bits of its matching X register.

Arguments & returns

For common AArch64 procedure calls, X0–X7 carry integer/pointer arguments. X0 commonly carries the return value. W0–W7 are used for 32-bit values.

SP / X29 / X30

SP tracks the stack. X29 is commonly the frame pointer. X30 is the link register and normally receives the return address after BL.

Flags

N = negative, Z = zero, C = carry, V = signed overflow. CMP updates flags without keeping the subtraction result.

iOS / UnityFramework

Address math, Mach-O / ASLR concepts, PC-relative ARM64 patterns, UnityFramework context, and LLDB commands in one offline workspace.

Core iOS idea: UnityFramework is a Mach-O image. Static tools show addresses relative to the image's preferred virtual layout; iOS applies an ASLR slide at runtime. If you already have a module runtime base and a module-relative RVA, the practical runtime formula is still runtime = base + RVA.

Mach-O ASLR Slide

preferred VM ↔ runtime
Relationship: runtime address = unslid VM address + ASLR slide. The slide applies to addresses from the same loaded Mach-O image.

ADRP + ADD Resolver

common iOS PIC pattern
A very common Mach-O pattern builds an address in two stages. ADRP produces a 4 KB page-relative address and ADD supplies the low 12-bit page offset. This calculator models the final arithmetic once you know the resolved ADRP page and ADD immediate.

Mach-O Sections You Will See

__TEXT

Executable code and read-only content. Function disassembly is commonly found in __TEXT,__text.

__DATA / __DATA_CONST

Writable or protected data, pointers, globals, and runtime structures. Protections can differ after loading.

__LINKEDIT

Linker metadata such as symbol/string tables and other link-edit information. It is not normal executable function code.

ASLR Slide

iOS relocates loaded Mach-O images. Runtime addresses differ from preferred VM addresses by the image's slide.

Apple ARM64 Calling Convention

X0–X7

Common integer/pointer argument registers. X0 also commonly carries integer/pointer return values.

V0–V7

SIMD/floating-point argument and result registers are used for floating-point/vector values.

X29 / X30

X29 is commonly used as the frame pointer; X30 is the link register holding a return address after BL/BLR.

SP alignment

The stack pointer is maintained at 16-byte alignment at ABI-defined boundaries. STP/LDP are common in prologues and epilogues.

ARM64 Quick Reference

UnityFramework + RVA

When an RVA is relative to UnityFramework's image base, runtime address = loaded UnityFramework base + RVA.

Memory

LDR loads from memory. STR stores to memory. In UnityFramework code, [X19,#0x200] means memory at X19 + 0x200.

Calls

BL calls a PC-relative target and writes the return location to X30. BLR calls through a register, common for indirect calls.

Mach-O PIC

ADRP + ADD/LDR sequences are common for building addresses to globals, tables, imports, and nearby data in position-independent code.

Compare

CMP A,B behaves like A-B for flag calculation only. B.EQ checks Z=1; B.NE checks Z=0.

Stack pair

STP/LDP commonly save and restore registers in function prologues/epilogues, especially X29, X30, and SP.
